A source generates time-stamped status updates that are processed either on the mobile device or on a mobile edge cloud (MEC) before delivery to a monitor. Using the MEC is faster but costly, so the scheduler must balance timeliness, measured by age of information, against MEC usage. We formulate this as an infinite-horizon Markov decision process with an average-cost criterion and prove that an optimal policy has an age-threshold structure that depends on how long an update has been in service.
